## Engineering Reliability at Scale

<CardGrid stagger>
	<Card title="The Open Specification" icon="document">
		A language-agnostic protocol for the Outbox pattern. Whether you use **Python, Java, or Rust**, Open Outbox defines a standard for event state and claiming logic to ensure total consistency across any stack.
	</Card>
	<Card title="High-Performance Relay" icon="rocket">
		A specialized infrastructure component optimized for extreme query efficiency. It ensures **at-least-once delivery** by bridging your database and message brokers with atomic transactional integrity.
	</Card>
	<Card title="Database-Native Scaling" icon="setting">
		Engineered for massive datasets. The architecture is optimized for **sub-millisecond coordination**, allowing multiple relay instances to scale horizontally without collisions or locking bottlenecks.

Open Outbox is engineered for minimal overhead. In our reference benchmarks:
- **Sub-1ms** average query latency on tables with 10M+ records.
- **Horizontal Scaling** tested with 20+ concurrent relay instances.
- **Zero-Collision** event claiming under high-concurrency loads.
